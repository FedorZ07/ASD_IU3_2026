# ЛР2 — бенчмарки

Программа `ru.bmstu.lab2.BenchmarksMain` выводит таблицы с фактическими замерами.
Запуск после сборки (Windows, из корня проекта):

```bash
java -cp "31-Zatoka/target/test-classes;31-Zatoka/target/classes" ru.bmstu.lab2.BenchmarksMain
```

Сначала выполните `mvn clean test` для компиляции тестовых исходников.
Программа лежит в `src/test/java` как вспомогательный измеритель, а не как часть реализуемой структуры..
Для измерения желательно запускать несколько раз на одной и той же машине.

Точные значения времени зависят от JDK, ОС, нагрузки процессора и работы сборщика мусора;
поэтому вместо вымышленных чисел их следует вставить после локального запуска.

| Структура | Операция | N | Среднее время, мс | Примечание |
|---|---|---:|---:|---|
| PriorityQueueCustom | add + poll | 10 000 | после запуска | min-heap |
| java.util.PriorityQueue | add + poll | 10 000 | после запуска | эталон |
| PriorityQueueCustom | add + poll | 50 000 | после запуска | min-heap |
| java.util.PriorityQueue | add + poll | 50 000 | после запуска | эталон |
| PriorityQueueCustom | add + poll | 100 000 | после запуска | min-heap |
| java.util.PriorityQueue | add + poll | 100 000 | после запуска | эталон |

**Вывод:** обе реализации поддерживают логарифмические операции вставки и извлечения.
Разница в замерах объясняется реализацией динамического массива, деталями сравнения,
JIT-компиляцией и нагрузкой системы. Замеры вставляются после запуска на компьютере студента.

## Построение кучи из 100 000 элементов (1D)

| Метод | Среднее время, мс | Асимптотика |
|---|---:|---|
| Последовательные `add` | после запуска | O(n log n) верхняя граница |
| Конструктор heapify | после запуска | O(n) |

Для честного замера подготовьте один массив `Integer[]` заранее, а в измеряемой
части выполняйте только построение кучи.
Измеритель `BenchmarksMain` проводит два прогревочных и пять измеряемых повторений
на одном массиве. Полученные на своей машине цифры нужно записать в таблицу и
кратко объяснить различия. Измерения ориентировочные, не заменяют JMH.
