# Лабораторная № 2 — расчёт асимптотики

## Задача 1A — минимальная очередь с приоритетом

В основе `PriorityQueueCustom<T>` лежит двоичная минимальная куча в массиве.
Для узла `i` индексы детей равны `2*i + 1`, `2*i + 2`, родителя — `(i - 1) / 2`.

| Операция | Время | Обоснование |
|---|---|---|
| `add` | O(log n) амортизированно | Просеивание вверх на высоту кучи; при заполнении копирование массива O(n) |
| `poll` | O(log n) | Корень заменяется последним элементом, просеивание вниз до листа |
| `peek` | O(1) | Чтение корня массива |
| `size` | O(1) | Чтение счётчика |
| `isEmpty` | O(1) | Сравнение счётчика с нулём |

Высота полной двоичной кучи с `n` элементами — O(log n). Удвоение массива
даёт суммарную стоимость копирований O(n) для n последовательных вставок,
поэтому `add` имеет амортизированную стоимость O(log n), но одиночная вставка
при расширении массива занимает O(n). Дополнительная память — O(n).

Пустая очередь: `peek` возвращает `null`, `poll` бросает `NoSuchElementException`.
`null` не допускается как элемент. Тесты сверяют порядок извлечения с
`java.util.PriorityQueue` (только в тестовом коде).
