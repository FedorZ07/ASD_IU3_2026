# Лабораторная № 2 — расчёт асимптотики

## Задача 1A — минимальная очередь с приоритетом

В основе `PriorityQueueCustom<T>` лежит двоичная минимальная куча в массиве.
Для узла `i` индексы детей равны `2*i + 1`, `2*i + 2`, родителя — `(i - 1) / 2`.

| Операция | Время | Обоснование |
|---|---|---|
| `add` | O(log n) амортизированно | Просеивание вверх на высоту кучи; при заполнении копирование массива O(n) |
| `poll` | O(log n) | Корень заменяется последним элементом, просеивание вниз до листа |
| `peek` | O(1) | Чтение корня массива |
| `size` | O(1) | Чтение счётчика |
| `isEmpty` | O(1) | Сравнение счётчика с нулём |

Высота полной двоичной кучи с `n` элементами — O(log n). Удвоение массива
даёт суммарную стоимость копирований O(n) для n последовательных вставок,
поэтому `add` имеет амортизированную стоимость O(log n), но одиночная вставка
при расширении массива занимает O(n). Дополнительная память — O(n).

Пустая очередь: `peek` возвращает `null`, `poll` бросает `NoSuchElementException`.
`null` не допускается как элемент. Тесты сверяют порядок извлечения с
`java.util.PriorityQueue` (только в тестовом коде).

## Задача 1B

Компаратор не меняет высоту двоичной кучи, поэтому `add` и `poll` сохраняют
амортизированную O(log n) и O(log n) соответственно; `peek` работает за O(1).

## Задача 1C

`remove` — O(n) за счёт линейного поиска, после которого просеивание O(log n).
Дополнительная память операции — O(1).

## Задача 1D

Конструктор копирует массив из `n` элементов за O(n), затем строит кучу методом Флойда.
Внутренние узлы обрабатываются от индекса `n / 2 - 1` до нуля.
Для высоты `h` число узлов не превышает O(n / 2^(h+1)), а один вызов `siftDown`
занимает O(h). Сумма O(n * Σ(h / 2^h)) = O(n).
Память — O(n) для внутренней копии массива. Исходный массив не меняется.
Для сравнения, последовательное добавление даёт верхнюю границу O(n log n).


## Задача 2A

Ожидаемые `put`, `get`, `containsKey`, `remove` — O(1) при достаточно
равномерном распределении хешей и загрузке не выше 0.75, худший случай
из-за коллизий — O(n). Ресайз O(n), но амортизированная вставка O(1).
`size`, `capacity` — O(1). Память O(capacity) для двух массивов.
Для `Integer.MIN_VALUE` применяется модуль по `long`, чтобы сохранить смысл `Math.abs(hashCode()) % capacity` без переполнения.
