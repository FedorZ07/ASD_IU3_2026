# Задача 13. Сортировка выбором

## Время: O(n^2)

Внешний цикл по `i` делает n - 1 шагов. На шаге `i` внутренний цикл
ищет минимум среди оставшихся n - i - 1 элементов.

Всего сравнений:
(n - 1) + (n - 2) + ... + 1 = n * (n - 1) / 2, это O(n^2).

Количество сравнений не зависит от входных данных: даже для уже
отсортированного массива алгоритм всё равно ищет минимум на каждом шаге.
Поэтому и лучший, и худший случай O(n^2).

Обменов не больше n - 1 (один на каждом шаге внешнего цикла), это O(n).

## Память: O(1)

Сортировка идёт на месте, в том же массиве.
Дополнительно используются только переменные `i`, `j`, `minIndex`, `temp`.
