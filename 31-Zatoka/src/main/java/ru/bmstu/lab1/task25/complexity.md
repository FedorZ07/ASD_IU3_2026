# Задача 25. Сумма элементов

## Время: O(n)

В методе `sum` один цикл по всем n элементам.
На каждой итерации одно сложение, это O(1).
Итого n * O(1) = O(n).

Быстрее нельзя: каждый элемент влияет на сумму,
поэтому каждый нужно прочитать хотя бы один раз.

## Память: O(1)

Кроме входного массива используются только переменные `sum` и `i`.
Их количество не зависит от n.

Сумма хранится в `long`, а не в `int`: при n до 10^5 и элементах
до 2^31 сумма может достигать примерно 2 * 10^14 и переполнить `int`.
