# Задача 19. Объединение двух отсортированных массивов

## Время: O(n + m)

Указатели `i` (по первому массиву) и `j` (по второму) только увеличиваются
и никогда не возвращаются назад. На каждой итерации любого из трёх циклов
в результат записывается ровно один элемент и ровно один указатель
сдвигается на 1. Всего элементов n + m, значит всех итераций вместе
ровно n + m, каждая за O(1). Итого O(n + m), как требует условие.

Для сравнения: если склеить массивы и отсортировать заново, получилось бы
O((n + m) log(n + m)), то есть медленнее. Слияние использует то,
что массивы уже отсортированы.

## Память: O(n + m)

Создаётся массив результата длины n + m. Кроме него используются только
переменные `i`, `j`, `k`. Меньше нельзя, потому что ответ сам состоит из n + m чисел.
