# Задача 2. Индекс первого вхождения

## Время: O(n)

В методе `findFirstIndex` один цикл по элементам массива.
На каждой итерации одно сравнение `arr[i] == x`, это O(1).

- Лучший случай: x стоит на первом месте, цикл заканчивается сразу, O(1).
- Худший случай: x нет в массиве или он стоит последним,
  тогда просматриваются все n элементов, O(n).

Итого в худшем случае O(n). Быстрее нельзя, потому что массив не отсортирован
и x может оказаться в любом месте.

## Память: O(1)

Кроме входного массива используется только переменная цикла `i`.
Её размер не зависит от n.
