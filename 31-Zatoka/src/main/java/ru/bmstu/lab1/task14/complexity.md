# Задача 14. Сортировка вставками

## Время: O(n^2) в худшем случае, O(n) в лучшем

Внешний цикл по `i` делает n - 1 шагов. На шаге `i` внутренний цикл `while`
сдвигает вправо элементы, которые меньше `arr[i]`, их не больше `i`.

- Худший случай: массив отсортирован по возрастанию (наоборот от нужного).
  Тогда каждый элемент сдвигается в самое начало, сдвигов
  1 + 2 + ... + (n - 1) = n * (n - 1) / 2, это O(n^2).
- Лучший случай: массив уже отсортирован по невозрастанию.
  Цикл `while` сразу останавливается, на каждом шаге одно сравнение,
  итого O(n).
- В среднем каждый элемент сдвигается примерно на половину левой части,
  это тоже O(n^2).

## Память: O(1)

Сортировка идёт на месте, в том же массиве.
Дополнительно используются только переменные `i`, `j`, `current`.
