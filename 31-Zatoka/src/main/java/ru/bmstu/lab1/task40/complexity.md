# Задача 40. Удаление дубликатов

## Идея (два указателя)

Массив отсортирован, поэтому все одинаковые числа стоят подряд.

- `read` идёт по всем элементам слева направо;
- `write` показывает, куда записать следующее новое число.
  Всё, что левее `write`, уже без повторов.

Если `arr[read]` не равен последнему записанному числу `arr[write - 1]`,
это новое число: записываем его в `arr[write]` и сдвигаем `write`.
Иначе это повтор, и его просто пропускаем.

Пример: [1, 1, 2, 2, 2, 3]

| read | arr[read] | действие   | начало массива | write |
|------|-----------|------------|----------------|-------|
| -    | -         | старт      | 1              | 1     |
| 1    | 1         | повтор     | 1              | 1     |
| 2    | 2         | записать   | 1 2            | 2     |
| 3    | 2         | повтор     | 1 2            | 2     |
| 4    | 2         | повтор     | 1 2            | 2     |
| 5    | 3         | записать   | 1 2 3          | 3     |

Ответ: первые 3 элемента — 1 2 3.

## Время: O(n)

Один цикл: `read` проходит массив один раз, каждая итерация — одно сравнение
и, возможно, одна запись, O(1). Итого O(n), как требует условие.

## Память: O(1)

Новый массив не создаётся, всё меняется на месте. Дополнительно используются
только переменные `read` и `write`, их количество не зависит от n.
