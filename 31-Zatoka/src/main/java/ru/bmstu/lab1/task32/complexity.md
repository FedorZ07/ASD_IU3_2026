# Задача 32. Сумма произведений пар

Простой способ — перебрать все пары двумя вложенными циклами — работает
за O(n^2): при n около 10^5 это примерно 5 * 10^9 умножений.
Условие требует O(n), поэтому используется префиксная сумма.

## Идея

Сгруппируем пары по правому элементу. Элемент a[j] стоит в паре
с каждым элементом левее него, поэтому все такие пары дают

a[j] * a[0] + a[j] * a[1] + ... + a[j] * a[j - 1] = a[j] * prefix,

где prefix = a[0] + ... + a[j - 1]. Сложив это по всем j, получаем ответ.

Пример: [1, 2, 3] → 2 * 1 + 3 * (1 + 2) = 2 + 9 = 11.
Проверка перебором: 1 * 2 + 1 * 3 + 2 * 3 = 11.

## Время: O(n)

Один цикл по n элементам. На каждом шаге одно умножение, одно сложение
ответа и одно сложение префикса. Числа в BigInteger здесь не больше
примерно 100 бит, поэтому каждая операция с ними занимает O(1).
Итого O(n).

## Память: O(1)

Кроме входного массива хранятся только `prefix`, `result`, `contribution`
и `j`. Их количество не зависит от n.

## Почему BigInteger

Каждое произведение до (2^31)^2, примерно 4.6 * 10^18, а пар около
n^2 / 2 = 5 * 10^9. Сумма может достигать примерно 2 * 10^28, а `long`
вмещает только до 9.2 * 10^18. Поэтому ответ хранится в `java.math.BigInteger`
(стандартный класс Java для длинных чисел). Префикс — сумма не более
10^5 чисел по 2^31, примерно 2 * 10^14, — помещается в `long`.
