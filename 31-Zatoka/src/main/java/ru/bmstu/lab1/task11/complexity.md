# Задача 11. Ближайший к среднему

## Время: O(n)

В методе `find` два цикла подряд (не вложенных):

1. Первый цикл считает сумму всех n элементов: n сложений, O(n).
2. Второй цикл для каждого элемента считает расстояние до среднего
   и сравнивает с лучшим: n шагов по O(1), O(n).

Итого O(n) + O(n) = O(n). Быстрее нельзя: чтобы узнать среднее,
нужно прочитать все элементы.

## Память: O(1)

Кроме входного массива используются только переменные
`n`, `sum`, `bestIndex`, `bestDistance`, `distance`, `i`.
Их количество не зависит от n.

## Почему без дробей

Среднее `sum / n` может быть дробным, а сравнение дробных чисел типа `double`
может давать ошибки округления. Расстояние `|a[i] - sum / n|` умножено на n:
`|a[i] * n - sum|`. Так как n > 0, порядок расстояний не меняется,
а считать можно точно, в целых числах `long`.

Переполнения нет: `|a[i] * n|` не больше 2^31 * 10^5, примерно 2 * 10^14,
и `|sum|` тоже не больше 2 * 10^14, а `long` вмещает до 9 * 10^18.
