# Задача 1. Максимум и минимум

## Время: O(n)

В методе `findMinMax` один цикл по элементам с 1 до n-1.
На каждой итерации два сравнения, это O(1).
Итого (n - 1) * O(1) = O(n).

Быстрее не получится: любой элемент может оказаться минимумом или максимумом,
поэтому каждый элемент надо посмотреть хотя бы один раз.

## Память: O(1)

Кроме входного массива используются только переменные `min`, `max`, `i`
и массив результата из двух чисел. Их количество не зависит от n.
